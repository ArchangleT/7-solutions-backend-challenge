# 🧠 AI Skills for Real Engineers

> A collection of skills and agents that turn ideas into shipped code.

🔗 **Website:** [https://www.aihero.dev/skills](https://www.aihero.dev/skills)

---

## 📦 Installation

Pick the skills and agents you use. The installer writes editable files into your project.

```bash
npx skills@latest add mattpocock/skills
```

---

## 🚀 The Main Flow

The **idea → ship** spine, in order.

> Start with `/grill-with-docs`

| # | Skill | Description |
|---|-------|-------------|
| 1 | [`/grill-with-docs`](#1--grill-with-docs) | Get interviewed about a plan, and record the decisions |
| 2 | [`/to-spec`](#2--to-spec) | Turn an agreed conversation into a written spec |
| 3 | [`/to-tickets`](#3--to-tickets) | Split a spec into small tickets an agent can build |
| 4 | [`/implement`](#4--implement) | Build a finished spec into code, test-first |
| 5 | [`/code-review`](#5--code-review) | Review a diff against your standards and the spec |

---

### 1. `/grill-with-docs`

> Get interviewed about a plan, and record the decisions.

```bash
npx skills@latest add mattpocock/skills --skill=grill-with-docs
```

---

### 2. `/to-spec`

> Turn an agreed conversation into a written spec.

```bash
npx skills@latest add mattpocock/skills --skill=/to-spec
```

---

### 3. `/to-tickets`

> Split a spec into small tickets an agent can build.

```bash
npx skills@latest add mattpocock/skills --skill=/to-tickets
```

---

### 4. `/implement`

> Build a finished spec into code, test-first.

```bash
npx skills@latest add mattpocock/skills --skill=/implement
```

---

### 5. `/code-review`

> Review a diff against your standards and against the spec.

```bash
npx skills@latest add mattpocock/skills --skill=/code-review
```
